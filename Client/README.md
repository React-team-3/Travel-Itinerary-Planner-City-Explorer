# TripCraft – Frontend

## Requirements
- Node.js
- npm

## Installation

1. افتح Terminal داخل فولدر `client`.
2. نفّذ الأمر:

```bash
npm install
```

## Run the Project

لتشغيل المشروع في وضع التطوير:

```bash
npm run dev
```

بعد التشغيل، هيظهر رابط محلي في الـTerminal. افتحه في المتصفح لمشاهدة المشروع.

## Important Notes
- لا تنشئ مشروع React جديدًا.
- لا تحذف أو تعدّل ملفات الإعدادات بدون الرجوع لمسؤول الـFrontend.
- قبل البدء في العمل، تأكد أنك على آخر نسخة من المشروع.
